# Regenerative landing page — design source

Built from `CVR Regen Page.fig` (exported 2026-09-07). This supersedes both the
PSD and the earlier `feature/regenerative-landing-page` branch — see the end of
this file for why that branch is not being continued.

## The live Figma is the reference

    https://www.figma.com/design/muIeDVJN5mgz3Ep0hualTF/CVR-Regen-Page

Read it through the Figma MCP server (`get_metadata` for the node tree,
`get_design_context` for a node's real properties, `download_assets` for its
source images). **Work from the node data, not from a render.**

That distinction is not academic. Everything below was measured off a
flattened PNG export and turned out to be wrong:

| Read from the render | What the node tree says |
|---|---|
| "Regenerative" is live Nexa Rust Script | Node 6:2 is a **placed image** — the texture speckle, white outline and shadow are baked in and cannot be reproduced with `text-stroke` |
| "WELCOME TO" is Ultra | **Rockwell Bold**, 58.1px, `letter-spacing: 10px`, rotated −1.78° |
| The sub-line is DIN Condensed | **Rockwell Regular**, 44.8px, `scaleX(0.95)` |
| The ribbon is a clipped rectangle | A **vector** with an irregular outline (node 5:33) |
| The sub-line band is a flat dark panel | `opacity: 0.4` with **`mix-blend-multiply`** — it darkens the photograph rather than covering it |

Node widths against the 2075px artboard: ribbon 28.9%, "WELCOME TO" 24.2%,
sub-band 35.8%, sub-line 34.4%, wordmark 68.0%.

## Reading the .fig offline

The file is a zip: `canvas.fig`, `thumbnail.png`, `meta.json`, and 70 embedded
images. `canvas.fig` is a fig-kiwi container whose document block is **ZSTD**,
not zlib — `strings` on it returns nothing useful, which is not evidence that it
cannot be read.

    ./scripts/qa/jammy/decode-fig.sh "<path>/CVR Regen Page.fig" out

That writes `out/data.bin`, which carries the copy, the layer names and the
font records.

Canvas is **2115 x 8509**.

## Type

The design uses the site's existing faces, not the Jammy stack:

| Face | Weights | Records |
|---|---|---|
| Ultra | 400 | 17 |
| Lato | 500, 700 | 9 |
| DIN Condensed | 700 | 6 |
| Nexa Rust Script B Shadow 2 | 400 | 3 |
| Rockwell | 400, 700 | 2 |

Checked against what `/regenerative` actually loads today:

- **Available:** Ultra 400, DIN Condensed 400/700, Lato 500, Rockwell 400/700
- **Missing:** `lato` 700 and `nexa-rust-script-shad-2` 400

Neither is a blocker. Lato 700 appears in only three records (nav and footer
furniture the existing site already renders its own way), and Nexa Rust is a
single script accent. Both are in the client's Adobe kit `gqk7pcv` or on Google
Fonts, so it is a loading change, not an asset request.

## Assets

70 embedded images; **52 carry real transparency** and 24 are 1500px+ wide.
This is the set that was missing when the page was first built: proper
cut-outs rather than crops off a flat composite.

Broadly: cut-out hens (several poses), the farmer with a carton, egg-carton
product shots, the soil cross-section vignette, pasture and barn photography,
torn-paper edges, wood and burlap textures, and the alpha masks that go with
them.

`ref/regen-fig/inventory.json` lists every image with its dimensions, mode,
byte size and whether it carries alpha. `ref/regen-fig/contact-sheet.png` shows
the 36 largest. The images themselves are **not committed** — 91MB — and are
regenerated by unzipping the .fig.

## Why the earlier branch is not being continued

`feature/regenerative-landing-page` is 9 commits ahead of an old main and 15
behind current main. It was built by extracting artwork from
`CVR-Regen-LP-R1-v2-clean.psd`, and 8 of 14 assets were cropped out of the flat
composite — the client's correction at the time was that only the Figma export
should be used. That branch also predates the consent work and the font-kit
change now on main.

Starting from current main with the real Figma assets is cleaner than rebasing
15 commits of PSD-derived work that the new file replaces. The old branch is
left in place rather than deleted, in case any of its geometry work is worth
referring back to.
