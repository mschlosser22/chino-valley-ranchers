# Regenerative landing page — fonts to add

Both families are on Adobe Fonts with web licensing, so no purchase is needed.
Add them to the **existing kit `gqk7pcv`** (the one already serving
proxima-nova, cubano and din-condensed) rather than creating a new project —
one `<link>`, no new dependency.

## What to add

**Rockwell** — https://fonts.adobe.com/fonts/rockwell
- Regular (400)
- Bold (700)

Used for the hero lockup ("welcome to", "Organic Regenerative Eggs").

**Nexa Rust** — https://fonts.adobe.com/fonts/nexa-rust
- Nexa Rust Script B Shadow 2
- Nexa Rust Script R Shadow 2

Used for the large script accents: "Regenerative" (278px in the design),
"Generation", "Get 'em here!", "We're certified!", "You want more?",
"Hear Chris talk".

The PSD names these styles exactly, and Adobe carries them under those names.

## Already covered by the kit

- **DIN Condensed** — nav, CTA buttons, footer
- **Ultra** — section headlines (also loads from Google Fonts site-wide)
- **Lato** — body copy (also Google Fonts)

## How

fonts.adobe.com -> search the family -> "Add to Web Project" -> select the
**existing** `Chino Valley` project -> save. Nothing to send us; the kit ID
does not change.

Keep the weight selection tight — each additional weight is another file on
every page load.
